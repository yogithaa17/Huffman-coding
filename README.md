# Huffman Coding in C++

A C++ implementation of the **Huffman Coding algorithm**, a lossless data compression technique that assigns variable-length binary codes to characters based on their frequencies.

## Concepts Used
- Binary Trees
- Priority Queues
- Greedy Algorithms
- Data Structures in C++

## Language
- C++

## File Structure
- `main.cpp` — Contains the Huffman Coding implementation.

## Key Features
- Builds a Huffman Tree using character frequencies.
- Generates binary codes for characters.
- Demonstrates the use of priority queues and binary trees for efficient coding.
